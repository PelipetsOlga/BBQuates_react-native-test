# Spec Delta

## Purpose

На экране сериала пользователь получает случайный эпизод этого сериала: название, номер сезона и серии, кадр, описание и создатели.

## ADDED Requirements

### Requirement: Загрузка случайного эпизода
По нажатию «Get Random Episode» приложение SHALL запросить `GET /episodes?production=<название сериала>` и показать один случайно выбранный эпизод из ответа. Пока идёт запрос, показывается индикатор загрузки. Статус ответа не 200, ошибка разбора или сетевая ошибка приводят к показу текста ошибки, как и при загрузке цитаты.

#### Scenario: Успешная загрузка
- **WHEN** пользователь нажимает «Get Random Episode», и сервер возвращает список эпизодов
- **THEN** вместо прежнего контента показывается карточка одного из эпизодов списка

#### Scenario: Пустой список эпизодов
- **WHEN** сервер вернул пустой список эпизодов
- **THEN** индикатор загрузки остаётся на экране, как в оригинальном iOS-приложении

### Requirement: Номер сезона и серии
Номер эпизода из API SHALL показываться в виде «Season N Episode M». N — первая цифра номера. M — оставшиеся цифры без ведущего нуля.

#### Scenario: Первая серия первого сезона
- **WHEN** номер эпизода `101`
- **THEN** показывается «Season 1 Episode 1»

#### Scenario: Двузначная серия
- **WHEN** номер эпизода `110`
- **THEN** показывается «Season 1 Episode 10»

### Requirement: Карточка эпизода
Карточка эпизода SHALL показывать сверху вниз, белым текстом:
- название эпизода (размер iOS `largeTitle`);
- «Season N Episode M» (`title2`);
- кадр эпизода целиком, со скруглением 15, а пока он грузится — индикатор;
- описание (`title3`), которое сжимается до половины размера и имеет отступ снизу;
- строки «Written By: …», «Directed By: …», «Aired: …».

Текст выровнен по левому краю. Фон полупрозрачный чёрный (прозрачность 0.6), скругление 25, отступы внутри и по бокам.

#### Scenario: Показ эпизода
- **WHEN** загружен эпизод с автором «Vince Gilligan»
- **THEN** на карточке есть строка «Written By: Vince Gilligan»
